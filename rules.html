To prevent data loss, you must manually save your purchased items as a backup file. Follow these steps:

  • On the Shop page, click the "Purchased" button in the bottom‑right corner.

  • A file named purchases.callbybreath.purchases will be downloaded. This file is encrypted and contains a complete list of your purchased items.
  • Keep this file in a secure location (e.g., cloud drive, external storage).

  • Select the previously saved .callbybreath.purchases file.
  • Your purchased items will reappear in the "Purchased" section, and download links will be accessible again.

A purchase code is a unique sequence that unlocks digital content (audio, artwork, video, etc.). Important points:

  • A code gives you access to the digital files; it does not grant commercial rights (see Section 2).
  • You can always retrieve your purchased items using the backup file, even without re‑entering the code.
